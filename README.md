# skills

Claude Code skills, packaged so anyone can drop them into their own project.

| Skill | What it does |
|---|---|
| [profit](profit/) | Reconcile El Dorado FC coin sales against eatransfer transfer costs into a per-cashout profit report. Tag-based: each seller marks their eatransfer orders with a personal name suffix and configures it in `config.json`. |

Each skill folder has its own README with install steps.
